TEST-RUN CONTROLS
Start a clean run:
window.dispatchEvent(new CustomEvent('dc-fk-runtime-test-run-start'));

Reset and begin another clean run:
window.dispatchEvent(new CustomEvent('dc-fk-runtime-test-run-reset'));

End the current run:
window.dispatchEvent(new CustomEvent('dc-fk-runtime-test-run-end'));

Request the current run report:
window.addEventListener('dc-fk-runtime-report', event => console.log(event.detail), { once: true });
window.dispatchEvent(new CustomEvent('dc-fk-runtime-report-request'));
